A laszlobiri jel és lockup. A jel egy monogram: nagy L és kis b egymás mellett, szögletes, háromszög-lapokra bontott (low-poly) formában; az L köd vagy fekete, a b narancs.

Használd palakék, fekete és fehéres felületen. A jel legalább 20 px széles. Védőtér: a jel szélességének 15%-a minden oldalon.

Ne forgasd el, ne nyújtsd, ne told össze a két betűt, és ne cserélj színt. A pontos geometriát és a szabályokat a README „A jel” része írja le.
